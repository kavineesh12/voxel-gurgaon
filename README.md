# Voxel Gurgaon — 100 Years

A voxel 3D diorama of Gurgaon that time-travels: click a year (1920 → 1940 →
1960 → 1980 → 2000 → NOW) and watch the city grow from a mud-brick railway
town in a sea of wheat fields into the CyberCity skyline. Built with Three.js.

- **Views**: Aerial · Straight · Eye level · Tour (slow cinematic orbit),
  plus free orbit/zoom/pan at any time, and a day/night toggle (N).
- **Timeline**: era buttons or ▶ to auto-play through the decades; each era
  has a history caption (HUDA 1977, Maruti 1983, DLF City, the metro...).
- **Style**: realistic voxel buildings (mud, brick, concrete, glass — no
  Lego), block people walking, era-correct traffic (bullock carts → lorries
  → cars → metro) and a train on the Delhi–Rewari line in every era.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5288.
